01

What it is

CX Agent Studio

A low-code platform for building chat and IVR voice agents — accessible enough for non-engineers to build with hands-on, flexible enough for developers to extend with custom code.

02

Who it's for

The tool is shaped around two audiences at once — and the fact that they share the same canvas is the point.

Builders without an engineering team

Product managers Support leads CX designers

Hands-on, low-code. No backend needed to ship a working agent.

Extensible by

Developers, when the use case demands it

Custom code Webhooks Integrations

Drop down into code only where the low-code canvas can't reach.
