The Data Foundation every agent stands on

Front-office chat, fan assistant, pro-code data controller — they all sit on top of the same data. What you stage now decides what they can answer later.

01

Why this task comes first

Every agent in this lab sits on the foundation you build here. Get it right and your agents are useful. Get it wrong and they hallucinate confidently when the stakes are highest.

02

Build the foundation in two halves

Two layers, two shapes of data, two kinds of question they unlock. Both can be pre-staged before any agent is built.

Layer 01 · Retrieval Built first

Documents, searched by meaning

Unstructured text, indexed for semantic search. Powers chat-style agents.

Contains
MLB Rulebook Scouting Profiles Historical Records
Answers questions like
  • What are the waiver rules?
  • Tell me about Hank Aaron's career.
Layer 02 · Analytical Built next

Structured data, computed and predicted

Rows, columns, and ML models. Queried and modeled on. Powers analytical agents.

Contains
Team Records Player Statistics Playoff Probability Model
Answers questions like
  • Which teams are most likely to make the postseason?
  • How do these two players compare statistically?
↑

Start with retrieval. Document ingestion takes time — kick it off first and the index will be ready by the time the structured layer is loaded and modeled.

03

A third source, arriving later

Some data can't be pre-staged. Current standings, today's scores, in-season stats — these have to be fetched the moment a question is asked.

Live · Fetched on demand
MLB Stats API
Today's scores · current standings · in-season player stats. Not pre-staged — the agent that needs it fetches it at the moment the question is asked.
